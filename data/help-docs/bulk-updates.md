# Bulk updates

A bulk update changes the value of many records in a folder at once, for example raising every price by 10%.

## Using the assistant
1. Open the folder you want to change.
2. In the assistant panel, describe the change, for example: "update the values in this folder by 10%".
3. The assistant shows a **preview**: every record that will change, with its old value and new value.
4. Check the preview. Click **Approve** to apply it, or **Cancel** to discard it.

Nothing is changed until you click **Approve**.

## Filters
You can limit the change to some records: "increase overdue invoices by 5%" or "lower prices of archived products by 20%".

## Rounding
Values are rounded to the nearest cent. Half a cent rounds up (13.585 becomes 13.59).

## Records changed after the preview
If someone edits a record after the preview was made, that record is **skipped** when you approve, and the results list marks it as "changed since preview". Make a new preview to include it.

## Who can make bulk updates
Folder owners and editors. Viewers can see a preview but cannot approve it.

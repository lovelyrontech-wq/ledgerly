# Getting started with Ledgerly

Ledgerly keeps your records in **folders**. A folder holds one type of record, such as invoices or products.

## Create a folder
1. Click **New folder** in the left sidebar.
2. Enter a name and pick a type: **Invoice** or **Product**.
3. Click **Create**. The folder opens empty.

## Add records
- Click **Add record** at the top of the folder to add one record.
- To add many at once, click **Import CSV**. See "Importing and exporting records".

## Ask the assistant
Open the assistant panel with the chat icon in the top-right corner. You can ask it how to do things ("how do I share a folder?") or ask it to change records ("increase all prices in this folder by 10%").

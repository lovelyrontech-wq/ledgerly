# Importing and exporting records

## Import from CSV
1. Open a folder and click **Import CSV**.
2. The file needs a header row. Required columns: `name`, `value`. Optional: `status`, `currency`, and any custom fields.
3. Check the preview of imported rows and click **Import**.

Values use a dot for decimals (`1250.50`). Rows with errors are listed and not imported.

## Export to CSV
Open a folder and click **Export → CSV**. The file includes every record in the folder, with all fields.
